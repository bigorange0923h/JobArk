日期：2026-09-23。此文件记录一次验证证据，不替代 GitHub Issue/Project 的协作任务状态。

## 实现范围

- 职位详情、编辑与归档、JD 原文快照历史、重复 URL 冲突及空白输入校验。
- JD 本地提取和可选 AI 解析；独立保存成功/失败解析产物，刷新后可回看，原文不被覆盖或裁剪。
- Profile/Resume 字面证据匹配及历史报告；固定输入版本，保留硬性条件、事实引用、缺口和未知项。英文技能使用边界匹配，避免 Java 命中 JavaScript。
- 可选 AI 简历筛选/重排、双侧预览和既有候选稿确认流程；模型不能新增或改写条目正文。
- Application 创建、重复申请确认、事件时间线、乐观锁与合法状态迁移；可回看申请绑定的历史简历版本。APPLIED 需人工确认，不发送外部申请。
- Dashboard 待处理职位、曾到达阶段的漏斗、来源、UTC 日趋势及版本样本统计；图表保留数值/表格替代。
- ESLint、路由懒加载、GitHub Actions 质量检查配置及架构/API 边界文档。

## 实际浏览器点验

仅使用合成资料与隔离测试库，未调用真实模型或招聘平台。

1. 新建职位、打开详情、查看原始 JD。
2. 本地解析显示原文条件；重新打开详情仍能读到解析历史。
3. 选择固定 JD/正式简历版本创建申请，时间线出现初始事件。
4. 勾选外部投递完成确认后记录 APPLIED，时间线新增事件。
5. Dashboard 图表、表格、来源与日期统计反映该申请。
6. 生成并展开资料匹配报告，缺证据显示未知，而非伪造满足结论。

## 验证边界

- 真实 AI 网关未配置，网关成功/失败由测试替身验证；需用户提供网关并确认数据流向后再做真实联调。协议不是商业模型的原生兼容接口，详见 `ai-gateway.md`。

- GitHub Actions 配置已落盘，但未推送，不能宣称远端 CI 已运行。没有创建提交或部署。
