# ADR 0007：JD 适配参考分与独立公司尽调

日期：2026-10-07。状态：接受，用户明确授权本轮需求。

后续决策更新 ADR 0003 的无总分范围，但保留旧报告语义。新报告 schema 为 jd-analysis-v2，overall_score 继续为空，reference_score 单独记录下界、上界、覆盖率、实际权重与算法版本。未知不得计零或取中间分。覆盖率达到 80% 且关键硬条件无未知才显示单一参考下界；阈值属于产品规则，不是招聘统计结论。

Matching 复用 MatchResult，新增可空 parse_result_id 外键；策略与条件评估冻结于 report_json，实际内容指纹包含所有相关输入。公司公开资料报告归 Job 所有，以确认实体和可追溯来源为前提；风险不混入能力分。AI 只提供受校验的条件评估，后端控制权重与建议。禁止自动淘汰、投递或宣称录用概率。

JD-only 放宽机会的公司关联及标题；Company.name 仍必填。新迁移回退会丢失新信息时必须拒绝，不能建立假数据来满足旧约束。

搜索仅发送确认的公司身份，不发送履历；模型匹配仅发送必要事实摘要，不发送联系方式。普通 chat/completions 不视为具备搜索能力。未配置、主体歧义、超时或部分来源不得变成通过尽调。
