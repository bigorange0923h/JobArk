# ADR 0005：招聘平台导入与自动访问边界

四站共用候选确认和持久化边界，各自使用 URL 来源适配器。首版只解析用户提供的正文/HTML，不自动访问站点。平台身份依据白名单详情 URL 与稳定 ID，正文提取使用单个 JobPosting JSON-LD 或用户正文，缺失字段由用户补全。

来源候选存于数据库，确认前不创建正式机会。确认写入原子化、同候选同载荷幂等；平台页面更新复用不可变快照，并校验预览时页面版本。跨平台不自动合并，不覆盖用户已确认的公司/岗位分类，不产生外部发送。

理由、许可核对、数据流向、失败场景和自动访问后续条件见 docs/job-collection-design.md；验收见 docs/requirements/job-collection.md。不引入新第三方服务或抓取依赖。
