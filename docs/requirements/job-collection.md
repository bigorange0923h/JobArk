# 招聘平台职位导入：首版需求

## 范围与非目标

支持领英、Indeed、BOSS 直聘、51job 的单个职位详情链接和用户提供的 HTML / 可见正文。网址用于识别平台与稳定职位 ID，不由后端访问。页面内容本地解析，预览候选可修正，明确确认后写入 Company、JobOpportunity、JobPosting、JobSnapshot。

首版不是已上线的网络爬虫或搜索聚合器。后台搜索、分页批量抓取、登录托管、抓取插件、验证码绕过、隐蔽接口和外部投递均不在范围内。自动访问须先验证平台许可、真实页面与可持续访问方式，不能用“用户登录了”代替平台许可。

## 验收

- 四个平台 URL 识别、跟踪参数移除、稳定 ID；拒绝伪造域名、凭据、非 HTTPS、非详情链接。
- HTML 仅解析 JobPosting JSON-LD；没有可靠结构时保留纯文本让用户填写公司、标题，不以页面导航推断职位事实。多个职位对象、登录/验证空页或空描述安全失败。文本模式由用户填写公司、标题，不能误称自动识别成功。
- 预览只保存独立导入候选，正式职位数量不变；不保存整个 HTML、脚本、Cookie 或浏览器会话，不外发 AI。
- 候选保存在数据库，24 小时过期；确认要求候选版本与明确确认。保存原始候选与人工修订，失败不写入半份职位。
- 同平台同 ID 更新已有页面；相同内容复用快照，A→B→A 正确更新当前内容。不同平台不自动合并公司或机会。
- 已有页面只更新 JD，不覆盖人工维护的公司/职位分类与标题；预览后页面变化返回 409，要求重新预览。重复确认相同内容与版本返回相同机会/页面/快照回执，改内容或版本重确认返回 409。
- 输入按 UTF-8 限制为 1 MiB，JD 最多 100,000 字符；确认锁等待最多 5 秒，超时回滚并安全返回 409，重试不能重复写入。取得锁后也必须检查候选有效期。
- 前端使用 Ant Design Vue：粘贴网址与内容、预览、人工补全、确认、取消；失败保留输入并给出可理解错误。明确显示平台、更新/新建、来源与人工补充边界。
- 自动访问能力暂为不可用，界面说明当前支持内容导入，不能宣称四站实时采集已验证。

依赖：现有 0011 数据边界、JobSnapshot 去重与当前页面指向。优先级：先建立可信导入闭环，再按获得许可的平台逐个接通网络适配器。
