# JD 分析与公司公开资料尽调

2026-10-07 用户授权的正式需求。本文定义范围及验收，不表示实现完成。

## 范围与依赖

P0 顺序为可信输入/JD-only → 确定性策略 → 条件与参考分；随后 P1 独立公司报告。复用 Profile、ProfilePreference、四类排除、JobParseResult、MatchResult。自动采集、调度、投递不在本轮实现范围。GitHub Issue/Project 仍为任务状态唯一来源。

## P0 输入

个人资料沿用保存、导入确认、归档、不可变修订。只有 raw_jd 也能保存，无档案仍能解析；公司和职位标题可空，Company.name 仍必填，不建占位公司。空白/超长输入返回 422，缺资源 404，版本冲突 409。保存、解析、匹配各自反馈，分析失败保留已保存 JD 与草稿。

策略由 ProfilePreference 管理：目标方向、地点、雇佣类型、远程、月薪币种与税前/税后口径；硬限制显式选择，旧偏好保持软偏好。版本随内容保存更新。优先名单支持完整名称、确认行业与岗位关键词，任一命中表示优先关注；不抵消黑名单、不增加分数。旧 exclusions 不转换、不启用；自由正则和仅白名单模式不交付。

## P0 规则和分析

复用 job/exclusions.py：确定黑名单/硬限制冲突优先于 REVIEW 和分数；未知、否定、歧义不放行，确定排除默认停止外部分析。名称全半角、英文边界、中文短语、C++/C#/Node.js、行业父子关系分别验证。公司分類只使用用户确认值。薪资只有同币种、同周期、同税口径才能比较；区间上界不能保证底线，跨底线为待确认。地点、远程、雇佣类型分开。

每个新 MatchResult 固定快照、成功解析、资料修订、可选同修订 ResumeVersion、必要偏好及规则内容/版本、评分/模型/提示版本。指纹覆盖实际内容；输入改变提示历史过期，不改写报告。解析引用必须属于快照且 PARSED。条件类别区分职责、必要条件、普通要求、加分项、福利；摘录必须逐字来自当次 JD，事实引用必须属于所选修订，未记录不等于能力为零。模型只提供评估、依据和追问，后端校验并计算最终分数。

## 参考分契约

六维权重：技能 3、职责 2、明确准入 1、薪资 1.5、地点工作方式 1.5、职业方向 1。条件锚点为 0/0.25/0.5/0.75/1；UNKNOWN 没有比值。技能名称对应不能自动给 1。必要条件权重 2、普通 1、加分 0.5；重复条件去重。明确不存在准入要求可 NOT_APPLICABLE，缺资料/薪资/策略必须 UNKNOWN。不适用维度移除后按剩余权重归一至 10。

后端保存原始计算：L=已知加权得分，U=L+未知权重，C=已知权重/10。C≥80% 且关键硬条件无未知才显示单一参考下界，同时显示范围；否则只显示范围和补充入口。四舍五入只用于显示。旧 overall_score 保持 null，新 reference_score 独立命名，旧 schema 可读，不回填。

确定排除：不建议投递；硬条件未知或低覆盖：先补充/确认；无门禁且覆盖达标 L≥8 优先准备，6≤L<8 可以考虑，L<6 当前优先级较低。上述是产品阈值，禁止称为录用概率、自动淘汰或自动投递许可。

外发前明确告知服务商、JD 与必要履历摘要、用途，不发送联系方式；取消仍能本地分析。网络前结束读事务；超时、无配置、校验失败各自保留安全错误。主入口自动固化已保存当前输入，历史版本仍可显式选择；切换后慢响应不覆盖新输入。

## P1 公司尽调

先确认法人/品牌/官网/城市和招聘主体；身份不清 WAITING_USER，无公司不生成报告，同名不合并。Job 拥有最小不可变报告与来源 JSON，不建通用知识库或多租户预留。默认独立搜索适配器后交现有模型总结；chat/completions 不假定联网，原生搜索未经真实能力验证不启用。

每个结论带来源 URL/标题、必要摘录、实体依据、来源类型、查询时间、可空发布时间、支持/反驳与可信理由；事实、推测、观点、未知分开。经营风险、业务发展、团队技术、工作体验、目标适用性分维度；匿名评论为低可信线索、转载去重、来源矛盾并列，不用投票制造结论。未搜到负面不是正常，融资不是盈利，公司博客不证明目标部门质量。

搜索只发公司身份，告知并记录联网确认。默认预算 6 查询/8 来源/90 秒总外部步骤/15 秒单请求；缓存 24 小时显示年龄，可显式刷新。未配置、不支持、超时、部分失败独立展示；公司失败不影响保存和基础匹配。风险另列，不改能力分。网页/JD 是不可信输入，SSRF、重定向、大小防护，验证码/付费/登录限制转人工，不绕过。搜索/模型无凭据仍交付接口、替身测试、配置与失败 UI，真实联网单列未验收。

## 验收

覆盖 JD-only/无档案/无链接、空白超长、404/422/409、跨快照解析、重复点击/慢响应、保存成功分析失败、外发取消、策略失效、旧报告；覆盖白黑冲突/否定/符号技能/薪资区间口径/行业父子/名称规范化；覆盖同输入复算/去重/引用/未知上下界/不适用归一/高分硬冲突/未验证事实。

公司覆盖同名主体、转载、过时、矛盾、匿名、无来源、未配置/超时/部分失败和提示注入。随机 schema 验证迁移升降级，不能安全回退时拒绝，不操作业务 schema。后端 Ruff/Pyright/Pytest，前端回归/lint/TypeScript/build，浏览器三页和窄屏另验；替身、真实模型、真实搜索、浏览器分别报告。
